# Bantay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Bantay, a local daemon that judges every tool call a cloud coding agent proposes (allow / ask / block) and redacts PII and secrets from traffic leaving the laptop, with a fine-tuned local model, a live dashboard, Claude Code hooks, and a reproducible benchmark table, by 2026-10-10 10:00 PHT.

**Architecture:** One Python daemon (`bantayd`, FastAPI on 127.0.0.1:4477) loads a 4-bit Qwen2.5-Coder-1.5B via MLX plus a LoRA adapter trained tonight. Decisions go rules → allowlist → model logit readout → reason generation. A reverse proxy route redacts user and tool-result content in Anthropic API requests and restores placeholders in streamed responses. Claude Code talks to the daemon through a PreToolUse hook and `ANTHROPIC_BASE_URL`.

**Tech Stack:** Python 3.12 (uv venv at `.venv`), mlx-lm 0.32, FastAPI + uvicorn, httpx, GLiNER (`urchade/gliner_multi_pii-v1`) + torch CPU, pytest. Claude Code 2.1.x hooks. Claude (cloud) for dataset generation only.

**Spec:** `docs/superpowers/specs/2026-10-09-bantay-design.md`

## Global Constraints

- Daemon binds `127.0.0.1:4477` only. Never 0.0.0.0.
- Decision latency target: p95 < 150 ms warm (rules ~1 ms, model one forward pass).
- Base model: `mlx-community/Qwen2.5-Coder-1.5B-Instruct-4bit`. Adapter committed at `adapters/bantay-lora/`.
- Hook fails **closed to `ask`** when the daemon is unreachable; it never crashes Claude Code and never hangs past 15 s.
- Rules never return `allow`; only `ask` or `block`. `allow` comes from the allowlist or the model.
- No cloud call anywhere in `bantay/` package code. Cloud is used only in `scripts/gen_data.py` and `scripts/bench_cloud.py`.
- Placeholders are `<TYPE_N>` (e.g. `<PERSON_1>`, `<API_KEY_2>`); mapping stays in daemon memory, never logged to disk.
- Commit after every task. No AI attribution trailers in commits.

## Review Focus

1. Chained commands (`ls && rm -rf ~`, `echo ok; cat .env`) — rules must scan the whole command, not the first segment. Test in Task 2.
2. Daemon down, or model still loading, when the hook fires — hook returns `ask` with a clear reason within the timeout, exits 0. Test in Task 6.
3. A placeholder split across two SSE chunks (`<PERS` + `ON_1>`) — the stream restorer must reassemble it. Test in Task 8.
4. A 200 KB tool result in the proxy — redaction must finish in bounded time (chunked, memoized) and must not drop content. Test in Task 7.
5. Malformed tool input (Bash with no `command`, Edit with only `old_string`, non-dict input) — engine returns a decision, never raises. Test in Task 4.
6. `.env.example` / `.env.sample` reads must NOT be blocked (false block on a routine file). Test in Task 2.

```python
from __future__ import annotations
import json
from dataclasses import dataclass, field, asdict
from typing import Literal

Verdict = Literal["allow", "ask", "block"]
LABELS: tuple[str, ...] = ("allow", "ask", "block")

@dataclass
class ToolCall:
    tool_name: str
    tool_input: dict
    cwd: str = ""
    branch: str = ""
    session_id: str = ""

    def __post_init__(self):
        if not isinstance(self.tool_input, dict):
            self.tool_input = {"value": str(self.tool_input)}

    @property
    def command(self) -> str:
        return str(self.tool_input.get("command", "") or "")

    @property
    def path(self) -> str:
        return str(self.tool_input.get("file_path", "") or self.tool_input.get("path", "") or "")

    def summary(self) -> str:
        t = self.tool_name
        if t == "Bash":
            return f"$ {self.command}"
        if t == "Read":
            return f"read {self.path}"
        if t in ("Write", "Edit", "MultiEdit"):
            return f"{t.lower().replace('multiedit','edit')} {self.path}"
        if t == "WebFetch":
            return f"fetch {self.tool_input.get('url', '')}"
        return f"{t} {json.dumps(self.tool_input)[:80]}"

    def text(self) -> str:
        """All text a rule might need to inspect."""
        parts = [self.command, self.path, str(self.tool_input.get("url", ""))]
        for k in ("content", "new_string", "old_string"):
            v = self.tool_input.get(k)
            if v:
                parts.append(str(v))
        for e in self.tool_input.get("edits", []) or []:
            if isinstance(e, dict):
                parts.append(str(e.get("new_string", "")))
        return "\n".join(p for p in parts if p)

@dataclass
class Decision:
    verdict: Verdict
    reason: str
    source: Literal["rule", "allowlist", "model", "error"]
    rule: str | None = None
    probs: dict[str, float] = field(default_factory=dict)
    latency_ms: float = 0.0

    def to_dict(self) -> dict:
        return asdict(self)
```

`bantay/prompts.py`:
```python
import json
from .types import ToolCall

SYSTEM = (
    "You are Bantay, a local safety judge for AI coding agents. You see one tool call an agent "
    "wants to run on a developer's machine. Decide:\n"
    "allow - routine, reversible, inside the project, no secrets or private data leave the machine.\n"
    "ask - risky but sometimes legitimate: force push, hard reset, deploys, publishing, deleting many "
    "project files, touching production data, changing shell/CI config, sudo installs.\n"
    "block - destructive outside the project, reads or prints credentials, exfiltrates secrets or "
    "private data, pipes downloads into a shell, escalates privileges, or is irreversible with no "
    "legitimate development reason.\n"
    "Answer with exactly one word on the first line: allow, ask, or block. "
    "If not allow, add a second line starting with 'Reason:' with one short sentence."
)

def render_call(call: ToolCall) -> str:
    raw = json.dumps(call.tool_input, ensure_ascii=False)
    if len(raw) > 1500:
        raw = raw[:1500] + "…"
    return f"Tool: {call.tool_name}\nInput: {raw}\nContext: cwd={call.cwd} branch={call.branch}"

def messages_for(call: ToolCall, label: str | None = None, reason: str | None = None) -> list[dict]:
    msgs = [{"role": "system", "content": SYSTEM}, {"role": "user", "content": render_call(call)}]
    if label:
        content = label if (label == "allow" or not reason) else f"{label}\nReason: {reason}"
        msgs.append({"role": "assistant", "content": content})
    return msgs
```

```python
from __future__ import annotations
import os, re
from dataclasses import dataclass
from typing import Callable
from .types import ToolCall, Decision, Verdict
from .secrets import SECRET_FILE_RE, find_secrets

@dataclass
class Rule:
    name: str
    tools: tuple[str, ...]
    verdict: Verdict
    reason: str
    pattern: re.Pattern | None = None
    predicate: Callable[[ToolCall], bool] | None = None

    def matches(self, call: ToolCall) -> bool:
        if call.tool_name not in self.tools:
            return False
        if self.predicate is not None:
            return bool(self.predicate(call))
        return bool(self.pattern and self.pattern.search(call.text()))

BASH = ("Bash",)
FILES = ("Write", "Edit", "MultiEdit", "NotebookEdit")
READS = ("Read",)
HOME = os.path.expanduser("~")

def _rx(p: str) -> re.Pattern:
    return re.compile(p, re.IGNORECASE | re.MULTILINE)

RM_RE = _rx(r"\brm\s+(?:-[a-z]*(?:r[a-z]*f|f[a-z]*r)[a-z]*|-r\s+-f|-f\s+-r|--recursive(?:\s+--force)?|-r\b)\s+(?P<targets>[^|;&]*)")
DANGEROUS_TARGET = _rx(r"(?:^|\s)(?:/|~|\$HOME|\*|\.\.|/(?:Users|home|etc|var|usr|opt|Library|System)\b)")

def _rm_outside(call: ToolCall) -> bool:
    for m in RM_RE.finditer(call.command):
        targets = m.group("targets").strip()
        if not targets:
            return True
        for t in targets.split():
            if t.startswith("-"):
                continue
            if DANGEROUS_TARGET.search(" " + t) or t in ("/", "~", "*", "."):
                return True
            if t.startswith("/") and call.cwd and not os.path.abspath(t).startswith(os.path.abspath(call.cwd) + os.sep):
                return True
    return False

def _rm_inside(call: ToolCall) -> bool:
    return bool(RM_RE.search(call.command)) and not _rm_outside(call)

def _force_push_main(call: ToolCall) -> bool:
    c = call.command
    if not re.search(r"\bgit\s+push\b.*(?:\s--force\b|\s-f\b)", c):
        return False
    if "--force-with-lease" in c:
        return False
    return bool(re.search(r"\b(?:main|master)\b", c)) or call.branch in ("main", "master")

def _force_push_other(call: ToolCall) -> bool:
    return bool(re.search(r"\bgit\s+push\b.*(?:--force(?:-with-lease)?\b|\s-f\b)", call.command)) and not _force_push_main(call)

def _sudo_destructive(call: ToolCall) -> bool:
    return bool(re.search(r"\bsudo\b.*\b(?:rm|dd|mkfs|chmod|chown|kill|launchctl|shutdown|reboot)\b", call.command))

def _secret_in_write(call: ToolCall) -> bool:
    body = "\n".join(str(call.tool_input.get(k, "")) for k in ("content", "new_string")) + \
        "\n".join(str(e.get("new_string", "")) for e in (call.tool_input.get("edits") or []) if isinstance(e, dict))
    return bool(find_secrets(body))

def _outside_cwd(call: ToolCall) -> bool:
    p = call.path
    if not p or not p.startswith("/") or not call.cwd:
        return False
    ap = os.path.abspath(p)
    if ap.startswith(os.path.abspath(call.cwd) + os.sep) or ap.startswith("/tmp") or ap.startswith("/private/tmp"):
        return False
    return True

def _url_has_secret(call: ToolCall) -> bool:
    return bool(find_secrets(str(call.tool_input.get("url", ""))))

RULES: list[Rule] = [
    # --- exfiltration / credential access (block) ---
    Rule("pipe_to_shell", BASH, "block", "Downloads a script and pipes it straight into a shell.",
         _rx(r"\b(?:curl|wget)\b[^|]*\|\s*(?:sudo\s+)?(?:ba|z|da|k)?sh\b")),
    Rule("reverse_shell", BASH, "block", "Opens a reverse shell to a remote host.",
         _rx(r"/dev/tcp/|\bnc\b.*\s-e\s|\bncat\b.*\s-e\s|\bsocat\b.*exec")),
    Rule("upload_file", BASH, "block", "Uploads a local file to a remote host.",
         _rx(r"\b(?:curl|wget|http)\b[^|;&]*(?:\s-d\s*@|--data(?:-binary|-raw|-urlencode)?\s*@|\s-F\s+\S*=@|\s-T\s|--upload-file)")),
```

```python
from __future__ import annotations
import threading, time
import mlx.core as mx
from .types import ToolCall, LABELS
from . import prompts

DEFAULT_MODEL = "mlx-community/Qwen2.5-Coder-1.5B-Instruct-4bit"

class Classifier:
    """One forward pass → logits over allow/ask/block. Reason generated only when asked."""
    def __init__(self, model_path: str = DEFAULT_MODEL, adapter_path: str | None = None):
        from mlx_lm import load
        self.model, self.tokenizer = load(model_path, adapter_path=adapter_path)
        self.name = model_path.split("/")[-1] + (f" + {adapter_path.rstrip('/').split('/')[-1]}" if adapter_path else "")
        self.label_ids = {}
        for lab in LABELS:
            ids = self.tokenizer.encode(lab, add_special_tokens=False)
            self.label_ids[lab] = ids[0]
        assert len(set(self.label_ids.values())) == 3, self.label_ids
        self._lock = threading.Lock()
        self.classify(ToolCall("Bash", {"command": "ls"}))  # warm-up / compile

    def _prompt_ids(self, call: ToolCall, suffix: str = "") -> list[int]:
        text = self.tokenizer.apply_chat_template(prompts.messages_for(call), add_generation_prompt=True, tokenize=False)
        return self.tokenizer.encode(text + suffix, add_special_tokens=False)

    def classify(self, call: ToolCall) -> tuple[str, dict[str, float]]:
        ids = self._prompt_ids(call)
        with self._lock:
            logits = self.model(mx.array([ids]))[0, -1]
            sel = mx.array([logits[self.label_ids[l]] for l in LABELS])
            probs = mx.softmax(sel.astype(mx.float32))
            mx.eval(probs)
        p = {l: float(probs[i]) for i, l in enumerate(LABELS)}
        return max(p, key=p.get), p

    def reason(self, call: ToolCall, label: str, max_tokens: int = 40) -> str:
        from mlx_lm import generate
        text = self.tokenizer.apply_chat_template(prompts.messages_for(call), add_generation_prompt=True, tokenize=False)
        with self._lock:
            out = generate(self.model, self.tokenizer, prompt=text + f"{label}\nReason:", max_tokens=max_tokens, verbose=False)
        return out.strip().split("\n")[0].strip() or f"{label} by local model"

class FakeClassifier:
    def __init__(self, label: str = "allow", probs: dict | None = None, reason_text: str = "fake reason"):
        self.label, self.name, self.reason_text = label, "fake", reason_text
        self.probs = probs or {l: (0.8 if l == label else 0.1) for l in LABELS}
        self.calls: list[ToolCall] = []
    def classify(self, call):
        self.calls.append(call); return self.label, dict(self.probs)
    def reason(self, call, label):
        return self.reason_text
```

```python
from __future__ import annotations
import re, time
from .types import ToolCall, Decision
from . import rules

ALLOWLIST_RE = re.compile(
    r"^\s*(?:ls|pwd|whoami|date|uname|which|type|wc|du|df|tree|file|stat|head|tail|cat|less|grep|rg|find|fd|diff"
    r"|git\s+(?:status|diff|log|branch|show|remote|fetch|stash\s+list|rev-parse|blame)"
    r"|npm\s+(?:test|run\s+(?:test|lint|build|typecheck|dev)|ls|-v|--version)|pnpm\s+(?:test|lint|build)|yarn\s+(?:test|lint|build)"
    r"|pytest|python3?\s+-m\s+pytest|ruff|eslint|prettier|tsc|cargo\s+(?:test|build|check|clippy)|go\s+(?:test|build|vet)|make\s+(?:test|lint|build)"
    r"|node\s+-v|python3?\s+--version|echo\s+[^$`]*)\b[^|;&>`$]*$"
)

class Engine:
    def __init__(self, classifier=None, block_floor: float = 0.35):
        self.classifier, self.block_floor = classifier, block_floor

    @property
    def model_name(self) -> str:
        return getattr(self.classifier, "name", "none")

    def decide(self, call: ToolCall) -> Decision:
        t0 = time.perf_counter()
        try:
            d = self._decide(call)
        except Exception as e:
            d = Decision("ask", f"judge error: {type(e).__name__}: {e}", "error")
        d.latency_ms = round((time.perf_counter() - t0) * 1000, 1)
        return d

    def _decide(self, call: ToolCall) -> Decision:
        if not isinstance(call.tool_input, dict):
            call.tool_input = {}
        d = rules.evaluate(call)
        if d:
            return d
        if call.tool_name == "Bash" and ALLOWLIST_RE.match(call.command):
            return Decision("allow", "Read-only or routine dev command.", "allowlist")
        if call.tool_name in ("Glob", "Grep", "LS", "TodoWrite", "Task"):
            return Decision("allow", "Read-only tool.", "allowlist")
        if self.classifier is None:
            return Decision("ask", "No local model loaded; defaulting to ask.", "error")
        label, probs = self.classifier.classify(call)
        if label == "allow" and probs.get("block", 0) >= self.block_floor:
            return Decision("ask", f"Model uncertain (block={probs['block']:.2f}); asking the human.", "model", probs=probs)
        reason = "Routine action inside the project." if label == "allow" else self.classifier.reason(call, label)
        return Decision(label, reason, "model", probs=probs)
```

```python
import asyncio, time
from collections import deque

class EventBus:
    def __init__(self, history: int = 200):
        self.subs: set[asyncio.Queue] = set()
        self.history: deque = deque(maxlen=history)
        self.stats = {"decisions": 0, "allow": 0, "ask": 0, "block": 0, "redactions": 0,
                      "secrets_redacted": 0, "pii_redacted": 0, "bytes_to_cloud_for_decisions": 0,
                      "bytes_proxied": 0, "latency_ms_sum": 0.0, "started": time.time()}

    def publish(self, event: dict):
        event.setdefault("ts", time.time())
        self.history.append(event)
        for q in list(self.subs):
            try:
                q.put_nowait(event)
            except asyncio.QueueFull:
                pass

    def record_decision(self, d: dict, summary: str, tool: str):
        s = self.stats
        s["decisions"] += 1; s[d["verdict"]] += 1; s["latency_ms_sum"] += d.get("latency_ms", 0)
        self.publish({"type": "decision", "tool": tool, "summary": summary, **d})

    def subscribe(self) -> asyncio.Queue:
        q: asyncio.Queue = asyncio.Queue(maxsize=500)
        self.subs.add(q); return q

    def unsubscribe(self, q): self.subs.discard(q)
```

```python
from __future__ import annotations
import asyncio, json, os, subprocess, time
from pathlib import Path
from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse, StreamingResponse, JSONResponse
from starlette.concurrency import run_in_threadpool
from .types import ToolCall
from .events import EventBus
from .engine import Engine

STATIC = Path(__file__).parent / "static"
_branch_cache: dict[str, tuple[float, str]] = {}

def git_branch(cwd: str) -> str:
    if not cwd: return ""
    now = time.time(); hit = _branch_cache.get(cwd)
    if hit and now - hit[0] < 5: return hit[1]
    try:
        b = subprocess.run(["git", "-C", cwd, "rev-parse", "--abbrev-ref", "HEAD"], capture_output=True, text=True, timeout=1).stdout.strip()
    except Exception:
        b = ""
    _branch_cache[cwd] = (now, b); return b

def create_app(engine: Engine, redactor=None, upstream: str = "https://api.anthropic.com") -> FastAPI:
    app = FastAPI(title="bantayd")
    bus = EventBus()
    app.state.engine, app.state.bus, app.state.redactor, app.state.upstream = engine, bus, redactor, upstream

    @app.get("/health")
    async def health():
        return {"ok": True, "model": engine.model_name, "redactor": getattr(redactor, "name", None)}

    @app.post("/decide")
    async def decide(req: Request):
        body = await req.json() if (await req.body()) else {}
        if not isinstance(body, dict): body = {}
        cwd = str(body.get("cwd", "") or "")
        call = ToolCall(str(body.get("tool_name", "") or "Unknown"), body.get("tool_input") or {}, cwd=cwd,
                        branch=git_branch(cwd), session_id=str(body.get("session_id", "") or ""))
        d = await run_in_threadpool(engine.decide, call)
        dd = d.to_dict()
        bus.record_decision(dd, call.summary(), call.tool_name)
        return dd

    @app.get("/stats")
    async def stats():
        s = dict(bus.stats)
        s["avg_latency_ms"] = round(s["latency_ms_sum"] / s["decisions"], 1) if s["decisions"] else 0
        s["model"] = engine.model_name
        return s

    @app.get("/events")
    async def events():
        q = bus.subscribe()
        async def gen():
            try:
                yield f"data: {json.dumps({'type': 'hello', 'history': list(bus.history)[-50:], 'stats': bus.stats})}\n\n"
                while True:
                    try:
                        ev = await asyncio.wait_for(q.get(), timeout=15)
                        yield f"data: {json.dumps(ev)}\n\n"
                    except asyncio.TimeoutError:
                        yield ": keepalive\n\n"
            finally:
                bus.unsubscribe(q)
        return StreamingResponse(gen(), media_type="text/event-stream", headers={"Cache-Control": "no-cache"})

    @app.get("/", response_class=HTMLResponse)
    async def index():
        return (STATIC / "index.html").read_text()

    if redactor is not None:
        from .proxy import attach_redact_routes
        attach_redact_routes(app)
    return app
```

```python
"""Claude Code PreToolUse hook: stdin JSON -> bantayd -> stdout JSON. Always exits 0."""
import json, os, sys, urllib.request, urllib.error

DEFAULT_URL = os.environ.get("BANTAY_URL", "http://127.0.0.1:4477")

def decide_via_daemon(payload: dict, url: str = DEFAULT_URL, timeout: float = 15.0) -> dict:
    try:
        req = urllib.request.Request(url.rstrip("/") + "/decide", data=json.dumps(payload).encode(),
                                     headers={"Content-Type": "application/json"}, method="POST")
        with urllib.request.urlopen(req, timeout=timeout) as r:
            return json.loads(r.read().decode())
    except Exception as e:
        return {"verdict": "ask", "reason": f"Bantay daemon unreachable ({type(e).__name__}); run `bantay serve`.", "source": "error"}

def to_hook_output(d: dict, allow_mode: str = "defer") -> dict | None:
    v = d.get("verdict", "ask")
    if v == "allow" and allow_mode != "allow":
        return None
    decision = {"allow": "allow", "ask": "ask", "block": "deny"}.get(v, "ask")
    reason = f"[bantay] {d.get('reason', '')}" + (f" (rule: {d['rule']})" if d.get("rule") else "")
    return {"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": decision, "permissionDecisionReason": reason}}

def main() -> int:
    try:
        raw = sys.stdin.read()
        data = json.loads(raw) if raw.strip() else {}
        if not isinstance(data, dict): raise ValueError("hook input not an object")
        payload = {"tool_name": data.get("tool_name"), "tool_input": data.get("tool_input"),
                   "cwd": data.get("cwd") or os.getcwd(), "session_id": data.get("session_id", "")}
        d = decide_via_daemon(payload)
    except Exception as e:
        d = {"verdict": "ask", "reason": f"hook error: {e}", "source": "error"}
    out = to_hook_output(d, os.environ.get("BANTAY_ALLOW_MODE", "defer"))
    if out:
        sys.stdout.write(json.dumps(out))
    return 0

if __name__ == "__main__":
    sys.exit(main())
```

```python
from __future__ import annotations
import re
from dataclasses import dataclass, field
from .secrets import SECRET_PATTERNS

def _luhn(s: str) -> bool:
    d = [int(c) for c in re.sub(r"\D", "", s)]
    if len(d) < 13: return False
    tot = 0
    for i, x in enumerate(reversed(d)):
        if i % 2: x *= 2; x -= 9 if x > 9 else 0
        tot += x
    return tot % 10 == 0

PII_PATTERNS: list[tuple[str, re.Pattern]] = [
    ("EMAIL", re.compile(r"\b[\w.+-]+@[\w-]+\.[\w.-]+\b")),
    ("PHONE", re.compile(r"(?<!\d)(?:\+63|0)9\d{2}[-\s.]?\d{3}[-\s.]?\d{4}(?!\d)")),
    ("TIN", re.compile(r"(?<!\d)\d{3}-\d{3}-\d{3}(?:-\d{3})?(?!\d)")),
    ("SSS", re.compile(r"(?<!\d)\d{2}-\d{7}-\d(?!\d)")),
    ("PHILHEALTH", re.compile(r"(?<!\d)\d{2}-\d{9}-\d(?!\d)")),
    ("CARD", re.compile(r"(?<!\d)(?:\d[ -]?){13,19}(?!\d)")),
]
SECRET_TYPE = {k: "API_KEY" for k in SECRET_PATTERNS}
SECRET_TYPE.update({"jwt": "TOKEN", "private_key_block": "PRIVATE_KEY", "db_url_password": "DB_URL", "generic_assignment": "SECRET"})
GLINER_LABELS = ["person", "address", "date of birth", "government id number", "bank account number", "credit card number"]
GLINER_TYPE = {"person": "PERSON", "address": "ADDRESS", "date of birth": "DOB", "government id number": "GOV_ID",
               "bank account number": "BANK_ACCOUNT", "credit card number": "CARD"}
PLACEHOLDER_RE = re.compile(r"<([A-Z_]+)_(\d+)>")

@dataclass
class RedactResult:
    text: str
    mapping: dict[str, str] = field(default_factory=dict)
    counts: dict[str, int] = field(default_factory=dict)

class Redactor:
    def __init__(self, use_gliner: bool = True, threshold: float = 0.5, gliner_model: str = "urchade/gliner_multi_pii-v1", chunk: int = 2000):
        self.forward: dict[str, str] = {}   # original -> placeholder
        self.reverse: dict[str, str] = {}   # placeholder -> original
        self.counters: dict[str, int] = {}
        self.threshold, self.chunk = threshold, chunk
        self._gliner = None; self.gliner_model = gliner_model; self.use_gliner = use_gliner
        self.name = "regex" + (" + gliner_multi_pii-v1" if use_gliner else "")
        self._cache: dict[int, RedactResult] = {}

    def _gl(self):
        if self._gliner is None and self.use_gliner:
            from gliner import GLiNER
            self._gliner = GLiNER.from_pretrained(self.gliner_model)
        return self._gliner

    def _ph(self, kind: str, original: str) -> str:
        if original in self.forward: return self.forward[original]
        self.counters[kind] = self.counters.get(kind, 0) + 1
        ph = f"<{kind}_{self.counters[kind]}>"
        self.forward[original] = ph; self.reverse[ph] = original
        return ph

    def _spans(self, text: str) -> list[tuple[int, int, str]]:
        spans = []
        for kind, pat in SECRET_PATTERNS.items():
            for m in pat.finditer(text):
                spans.append((m.start(), m.end(), SECRET_TYPE[kind]))
        for kind, pat in PII_PATTERNS:
            for m in pat.finditer(text):
                if kind == "CARD" and not _luhn(m.group(0)): continue
                spans.append((m.start(), m.end(), kind))
        gl = self._gl()
        if gl is not None:
            for off in range(0, len(text), self.chunk):
                piece = text[off: off + self.chunk]
                for e in gl.predict_entities(piece, GLINER_LABELS, threshold=self.threshold):
                    spans.append((off + e["start"], off + e["end"], GLINER_TYPE[e["label"]]))
        spans.sort(key=lambda s: (s[0], -(s[1] - s[0])))
        out, last = [], -1
        for s in spans:  # drop overlaps, keep earliest/longest
            if s[0] >= last: out.append(s); last = s[1]
        return out

    def redact(self, text: str) -> RedactResult:
        if not text: return RedactResult(text or "")
        key = hash(text)
        if key in self._cache: return self._cache[key]
        counts: dict[str, int] = {}; mapping = {}; parts = []; pos = 0
        for start, end, kind in self._spans(text):
            orig = text[start:end]; ph = self._ph(kind, orig)
            parts.append(text[pos:start]); parts.append(ph); pos = end
            counts[kind] = counts.get(kind, 0) + 1; mapping[ph] = orig
        parts.append(text[pos:])
        res = RedactResult("".join(parts), mapping, counts)
        if len(self._cache) > 2000: self._cache.clear()
        self._cache[key] = res
        return res

    def restore(self, text: str) -> str:
        return PLACEHOLDER_RE.sub(lambda m: self.reverse.get(m.group(0), m.group(0)), text or "")

class StreamRestorer:
    """Restores placeholders across chunk boundaries; holds back a partial '<...' for up to 24 chars."""
    def __init__(self, redactor: Redactor, max_hold: int = 24):
        self.r, self.buf, self.max_hold = redactor, "", max_hold
    def feed(self, chunk: str) -> str:
        self.buf += chunk
        i = self.buf.rfind("<")
        if i == -1 or ">" in self.buf[i:] or len(self.buf) - i > self.max_hold:
            out, self.buf = self.r.restore(self.buf), ""
            return out
        out, self.buf = self.r.restore(self.buf[:i]), self.buf[i:]
        return out
    def flush(self) -> str:
        out, self.buf = self.r.restore(self.buf), ""
        return out
```

```python
            m["content"] = _redact_text(c, r, n)
        elif isinstance(c, list):
            for block in c:
                if not isinstance(block, dict): continue
                if block.get("type") == "text":
                    block["text"] = _redact_text(block.get("text", ""), r, n)
                elif block.get("type") == "tool_result":
                    tc = block.get("content")
                    if isinstance(tc, str): block["content"] = _redact_text(tc, r, n)
                    elif isinstance(tc, list):
                        for b in tc:
                            if isinstance(b, dict) and b.get("type") == "text":
                                b["text"] = _redact_text(b.get("text", ""), r, n)
    return body, n[0]

def restore_sse_line(line: str, s: StreamRestorer) -> str:
    if not line.startswith("data:"): return line
    try:
        ev = json.loads(line[5:].strip())
    except Exception:
        return line
    d = ev.get("delta") or {}
    if d.get("type") == "text_delta" and "text" in d:
        d["text"] = s.feed(d["text"])
    elif d.get("type") == "input_json_delta" and "partial_json" in d:
        d["partial_json"] = s.feed(d["partial_json"])
    elif ev.get("type") == "message_stop":
        tail = s.flush()
        if tail:
            return 'data: ' + json.dumps({"type": "content_block_delta", "index": 0, "delta": {"type": "text_delta", "text": tail}}) + "\n" + line
    else:
        return line
    return "data: " + json.dumps(ev)

def _restore_json(obj, r: Redactor):
    if isinstance(obj, str): return r.restore(obj)
    if isinstance(obj, list): return [_restore_json(x, r) for x in obj]
    if isinstance(obj, dict): return {k: _restore_json(v, r) for k, v in obj.items()}
    return obj

def attach_redact_routes(app: FastAPI):
    r: Redactor = app.state.redactor; bus = app.state.bus; upstream: str = app.state.upstream.rstrip("/")
    client = httpx.AsyncClient(transport=_transport(), timeout=httpx.Timeout(600, connect=10))

    @app.post("/redact")
    async def redact_ep(req: Request):
        body = await req.json(); res = r.redact(str(body.get("text", "")))
        bus.stats["redactions"] += 1
        bus.publish({"type": "redact", "original": str(body.get("text", ""))[:2000], "redacted": res.text[:2000], "counts": res.counts})
        return {"text": res.text, "counts": res.counts}

    @app.api_route("/anthropic/{path:path}", methods=["GET", "POST", "DELETE"])
    async def anthropic_proxy(path: str, req: Request):
        raw = await req.body(); headers = {k: v for k, v in req.headers.items() if k.lower() not in HOP}
        headers["accept-encoding"] = "identity"
        send = raw
        if path.endswith("/messages") and raw:
            try:
                body = json.loads(raw); before = raw
                body, n = redact_messages_body(body, r)
                send = json.dumps(body).encode()
                bus.stats["bytes_proxied"] += len(send)
                if n:
                    bus.stats["redactions"] += 1
                    secrets = sum(v for k, v in r.counters.items() if k in ("API_KEY", "TOKEN", "SECRET", "PRIVATE_KEY", "DB_URL"))
                    bus.stats["secrets_redacted"] = secrets; bus.stats["pii_redacted"] = sum(r.counters.values()) - secrets
                    last = body["messages"][-1]; orig = json.loads(before)["messages"][-1]
                    bus.publish({"type": "redact", "original": json.dumps(orig.get("content"))[:2000], "redacted": json.dumps(last.get("content"))[:2000], "placeholders": n})
            except Exception as e:
                bus.publish({"type": "error", "where": "proxy-redact", "error": str(e)})
        up = client.build_request(req.method, f"{upstream}/{path}", headers=headers, content=send, params=dict(req.query_params))
        resp = await client.send(up, stream=True)
        ctype = resp.headers.get("content-type", "")
        passthrough = {k: v for k, v in resp.headers.items() if k.lower() not in HOP | {"content-encoding"}}
        if "text/event-stream" in ctype:
            s = StreamRestorer(r)
            async def gen():
                buf = ""
                async for chunk in resp.aiter_text():
                    buf += chunk
                    while "\n" in buf:
                        line, buf = buf.split("\n", 1)
                        yield restore_sse_line(line, s) + "\n"
                if buf: yield restore_sse_line(buf, s)
                await resp.aclose()
            return StreamingResponse(gen(), status_code=resp.status_code, headers=passthrough, media_type="text/event-stream")
        data = await resp.aread(); await resp.aclose()
        if "application/json" in ctype:
            try:
                return JSONResponse(_restore_json(json.loads(data), r), status_code=resp.status_code)
            except Exception:
                pass
        return Response(content=data, status_code=resp.status_code, headers=passthrough)
```

```python
#!/usr/bin/env python3
"""Generate labeled tool-call examples with cloud Claude (teacher). Output: data/raw/<cat>_<label>_<i>.jsonl"""
import json, os, subprocess, sys, concurrent.futures as cf
from pathlib import Path
RAW = Path("data/raw"); RAW.mkdir(parents=True, exist_ok=True)
CATS = {  # name: (label, description)
  "read_source": ("allow", "reading or searching source files inside the project with cat/grep/rg/head or the Read tool"),
  # ... every category above, one line each ...
  "ph_pii_leak": ("block", "sending Filipino customer PII (names, GCash numbers, TIN/SSS, addresses) to external services, pastebins, webhooks, or hardcoding it into committed files"),
}
PROMPT = """You generate training data for a local safety classifier that judges tool calls made by AI coding agents.
Category: {cat} — {desc}. Required label: {label}.
Produce exactly {n} diverse, realistic examples as JSON Lines (one JSON object per line, no code fences, no commentary).
Schema: {{"tool_name": "Bash"|"Read"|"Write"|"Edit"|"WebFetch", "tool_input": {{...}}, "cwd": "/Users/<name>/<repo>", "branch": "<branch>", "label": "{label}", "reason": "<one short sentence>", "category": "{cat}"}}
tool_input schemas: Bash {{"command"}}, Read {{"file_path"}}, Write {{"file_path","content"}}, Edit {{"file_path","old_string","new_string"}}, WebFetch {{"url","prompt"}}.
Vary repos (Next.js, Django, Go, Laravel, React Native, Supabase), platforms (macOS, Linux), command styles (flags, chaining with && ; |), and include some Filipino developer context. Avoid repeating commands. Batch seed: {seed}."""

def gen(cat, label, desc, i, n=40):
    out = RAW / f"{cat}_{label}_{i}.jsonl"
    if out.exists(): return out
    env = {k: v for k, v in os.environ.items() if k != "CLAUDECODE"}
    p = subprocess.run(["claude", "-p", PROMPT.format(cat=cat, desc=desc, label=label, n=n, seed=i), "--output-format", "text"],
                       capture_output=True, text=True, env=env, timeout=600)
    rows = []
    for line in p.stdout.splitlines():
        line = line.strip().strip("`")
        if not line.startswith("{"): continue
        try:
            r = json.loads(line)
            if r.get("label") == label and isinstance(r.get("tool_input"), dict) and r.get("tool_name"):
                r["category"] = cat; rows.append(r)
        except json.JSONDecodeError:
            pass
    out.write_text("\n".join(json.dumps(r, ensure_ascii=False) for r in rows) + "\n")
    print(f"{out.name}: {len(rows)} rows", file=sys.stderr); return out

if __name__ == "__main__":
    jobs = [(c, l, d, i) for c, (l, d) in CATS.items() for i in range(int(sys.argv[1]) if len(sys.argv) > 1 else 2)]
    with cf.ThreadPoolExecutor(4) as ex:
        list(ex.map(lambda j: gen(*j), jobs))
```
